# 1.8.5 源码与 Windows 发布检查

核对日期：2026-10-11。

## 本地验证

- 433 项逻辑测试通过，包含真实只读 SQLite 迁移、Windows/UNC 视频地址、备份恢复和照片同步。
- `npm test` 通过：包含真实 Electron 的饮食同步、节律、图标与月历写入/重启检查。
- 视频收藏夹、柔和控件、认知计划与摄像头流程的隔离 Electron 集成通过。
- Mac arm64 构建成功；打包程序用 `test:release` 检查版本、源码哈希、页面、实际视频播放、照片保存与进程重启。
- 发布快照只包括源码、静态素材、测试和开发文档。个人记录、照片、密钥、备份、私有验收截图和本机工作日志不进入源码或程序包。

## Windows 验证与发布

工作流：[Windows build and release](https://github.com/SJT-bright/face-reshape-plan/actions/workflows/release-windows.yml)。原生 Windows runner 依次执行逻辑与 Electron 集成、默认资料目录检查、NSIS 打包、打包程序启动、合成视频解码播放、设置与照片保存、重启恢复、静默安装和安装后的程序启动。只有全部步骤通过，才发布安装 EXE、完整 ZIP、`SHA256SUMS.txt` 和 `windows-validation.json`。

Windows 默认用户目录为 `%APPDATA%\面部重塑计划\`，媒体保存在用户目录，安装/卸载保留资料。Mac 保留现有目录兼容行为；本次未更新正在使用的正式 Mac 应用。

测试视频 `tests/fixtures/synthetic.webm` 是纯色合成视频。测试照片为合成样本；摄像头自动测试不代表真实硬件拍摄，在线 B 站/抖音及付费 AI 服务也不在本次跨平台自动验收范围。

参考：[Electron Windows 应用标识](https://www.electronjs.org/docs/latest/api/app#appsetappusermodelidid-windows)、[Node SQLite 只读模式](https://nodejs.org/docs/latest-v24.x/api/sqlite.html)、[NSIS 构建参数](https://www.electron.build/v26/docs/nsis/)。
