# v1.5.0 更新说明

## 耐力评分 v2 —— 绝对常模分

- **第一天就有分**：耐力分从「对比自己过去 28 天的趋势」改为「单次表现对照动作常模的绝对 0–100 分」。录一次「俯卧撑 20 个」或「卧推 12 次 × 35kg」，立刻知道自己的耐力水平。
- **取最高值，不累加**：同一肌群练了多个动作时，用**最佳动作**代表该肌群（俯卧撑 50 个 → 胸部耐力按俯卧撑评价），不再把各动作容量平均。
- **四条打分路径**：负重动作（同窗重组锚点 → %1RM 预测次数比分表）→ 经典动作查性别×年龄常模表（俯卧撑/引体/卷腹/仰卧起坐）→ 其余自重动作按负荷档曲线 → 无锚动作通用宽档估计。
- 性别与年龄来自「我的基础数值」；未填性别用合并宽松档（分数置信度降低）。趋势改为 ↑/↓ 提示，不进分数。
- 历史回看按新口径重算，升级后耐力相关分数会出现一次跳变，属预期。

## 首页「现在做什么」自选板块

- 默认只显示 4 个核心板块：选择视频开练、今日力量、护理、视频库。
- 点「添加板块」（3D 加号）可添加 记一餐 / 记睡眠 / 记皮肤，也可移除任何板块、随时加回。
- 板块按添加顺序排成**每行最多两个**的有序网格；配置随数据持久化。
- 「现在做什么」标题顶格显示。
