# 饮食与睡眠：后台证据与计算规则

检索与审阅日期：2026-09-12。规则版本：2026-09-12.1。应用版本：1.2.1。

本文件供开发、复核和维护使用，不作为应用里的阅读内容。运行时证据注册表为 `src/js/rhythm-evidence.js`，计算实现为 `src/js/rhythm-engine.js`。每条提醒返回规则来源 ID，界面只显示具体记录和习惯提示。检索以 PubMed、PMC 和期刊原始论文为主；这是针对功能设计的定向证据整理，不是系统综述，也不是经过临床验证的预测模型。

## 证据如何约束功能

| 后台来源 | 证据与适用边界 | 产品决定 |
| --- | --- | --- |
| [AASM/SRS 成人睡眠共识，2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4434546/) | 建议 18–60 岁成年人经常每夜至少睡 7 小时。睡眠还涉及质量、规律和疾病因素。 | 用户选择相应年龄与日间作息后，才启用成人习惯提醒。记录的是自报睡眠时段，不能确认实际睡着多久。累计短时段仅提示留出睡眠时间。 |
| [Vujović 等，Cell Metabolism，2022](https://pubmed.ncbi.nlm.nih.gov/36198293/) | 严控摄入、活动、睡眠等条件的短期交叉试验发现延迟进食影响饥饿、能量消耗及脂肪组织相关通路。 | 可以关注反复靠近睡前的进食模式；不把机制变化转换成个人脂肪增减。 |
| [Gu 等，JCEM，2020](https://pubmed.ncbi.nlm.nih.gov/32525525/) | 20 名健康志愿者，固定 23:00–07:00 睡眠，比较 18:00 和 22:00 晚餐，发现急性代谢差异。 | 使用相对睡前间隔，不规定所有人必须几点吃晚餐。不能据此计算长期肥胖或糖尿病概率。 |
| [ACG GERD 指南，2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC8754510/) | 避免睡前 2–3 小时进餐是针对胃食管反流的条件性建议，证据等级低。 | 反复在睡前两小时内进餐时，只在“若有夜间反酸”的条件下提出提前晚餐的建议。不诊断反流，也不把加餐一律判为有害。 |
| [Alhussain 等，AJCN，2016](https://pubmed.ncbi.nlm.nih.gov/27305952/) | 11 名正常体重女性的短期交叉试验比较固定餐次与每天变化的餐次；部分代谢指标不同。 | 支持记录规律，但不支持把餐次试验直接变成“偏移 60 分钟就有疾病风险”的阈值。 |
| [Chaput 等，睡眠规律与心血管事件队列](https://pubmed.ncbi.nlm.nih.gov/39603689/) | 72,269 名英国成年人、设备测量、前瞻性观察。相关性不能代替因果或个体风险预测。 | 自报时刻的波动只做趋势；本产品不计算设备 SRI，不移植风险比。 |
| [Liu 等，NEJM，2022](https://pubmed.ncbi.nlm.nih.gov/35443107/) | 139 名肥胖参与者的 12 个月随机试验：限时进食加热量限制，对比单独热量限制，未显示额外减重或体脂收益。 | 不奖励更长空腹、不推荐跳餐，也不估算体脂率。 |
| [Dote-Montero 等，Nature Medicine，2025](https://www.nature.com/articles/s41591-024-03375-y) | 197 名参与者、12 周；早、晚及自选进食窗口相较常规照护未显示额外内脏脂肪改善。 | 不把进食窗口缩短包装为必然改善内脏脂肪的指标。 |
| [Dhurandhar 等，AJCN，2014](https://pubmed.ncbi.nlm.nih.gov/24898236/) | 309 人随机试验中，吃或不吃早餐的建议未对减重产生可辨别的影响。不是起床后不同分钟数的比较试验。 | 起床至首次进食仅描述，不设置“起床后 30/60 分钟必须吃”的规则。 |
| [Snijders 等，J Nutrition，2015](https://pubmed.ncbi.nlm.nih.gov/25926415/) | 44 名年轻男性，训练期间睡前蛋白补充对比无热量安慰剂；补充组增肌更明显。总蛋白不匹配，不能分离时间作用。 | 肌肉变化还依赖训练、蛋白与总营养。不从时间日志推断肌肉增长，更不外推到面部肌肉；不能认为所有睡前摄入都损害增肌。 |
| [Oyetakin-White 等，Clinical & Experimental Dermatology，2015](https://pubmed.ncbi.nlm.nih.gov/25266053/) | 60 名白人女性的观察性研究：睡眠质量与皮肤老化、屏障恢复有关。 | 不能仅凭睡觉时间推断睡眠质量，也不能计算皮肤损伤、衰老速度或面部脂肪。 |

## 数据与时间口径

- 新增独立 `rhythm` 命名空间，保留原有训练、护肤、设置及未知字段。记录、编辑、删除和确认完整性均通过原有本地 JSON 原子写入，不上传健康记录。
- 进餐：吃完的大致时间，可选正餐或加餐；两者均计入进食事件。保存本地墙钟字符串、UTC 时间戳和当时的时区偏移。没有食物、热量、蛋白或体重输入。
- 睡眠：早上一次填写入睡、起床时刻，可记主要睡眠和午睡。起床日期使用页面所选日期，入睡时刻晚于起床时刻时自动归入前一天，否则归入同一天。可选填手环实际睡眠时长，统计优先使用该值；未填时按时段跨度估算。手环值为手动转录，不是自动设备同步。
- 日期、未来事件、重复同分钟进餐、反向/重叠睡眠会被拦截；单段超过 24 小时只作为录入检查，不是医学阈值。手环时长必须为正整数分钟，且不能超过入睡至起床的跨度。新版不新增未填起床时间的记录；旧版未完成记录保留在折叠区，不参与统计，也不阻塞后续完整日。
- 进餐落在睡眠时段内可能是夜间醒来、补记误差或日期错误；该段睡眠及其关联间隔暂不参与统计。保留原记录，请用户自行核对。
- 每个自然日可分别确认饮食和睡眠已记全（睡眠包含当天结束的午睡）。增删改对应数据会撤销相关日期的确认。没有记录不等于零摄入或零睡眠。
- 趋势窗口是截至昨天的最近 7/30 个自然日。今天仍可记录与确认，从次日计入；不把尚未结束的一天当作完整观察。
- 跨时区的进餐/睡眠配对会排除；不作旅途健康判断。夏令时的睡眠长度用时间戳计算；不存在的当地时间会被拒绝。手工输入依据录入时系统时区，跨时区旅行的旧记录只宜参考。

## 统计和规则

| 项目 | 算法 / 门槛 | 输出边界 |
| --- | --- | --- |
| 平均睡眠时长 | 已确认且有有效睡眠的结束日，各段优先使用手环时长，未填则使用时段跨度；主要睡眠与午睡相加后再按日平均。零记录日不当作 0 小时。 | 区分手环转录数据与时段估算，不等于睡眠质量。用含午睡合计来触发偏短提醒是保守选择，不意味着午睡完全替代夜间睡眠。 |
| 进餐到睡前 | 每个完整睡眠日选最长主要睡眠；在其开始前 24 小时内找最后一次进食。所跨自然日的进食记录都须已确认。 | 分钟差的平均数。24 小时是匹配上限，超过或无记录时留空，不判为空腹。 |
| 起床到首次进食 | 上述主要睡眠结束后，找下一次主要睡眠前、且不超过 24 小时的首次进食。跨过的自然日须已确认且已经结束。 | 描述性平均数，无“太晚吃早餐”的风险阈值。 |
| 相邻进餐间隔 | 每个已记全自然日内部，相邻两次进食时间相减；不混入跨夜空档。 | 不指定健康的固定餐间隔。 |
| 进食跨度 | 至少有两次进食的完整日，其最后一次与第一次进食之差，再按日平均。 | 不是推荐的限时进食窗口；单次记录日不显示 0 小时跨度。 |
| 进食/就寝时刻波动 | 24 小时环形标准差，正确处理 23:50 与 00:10。首餐是自然日内第一次进食，可能是加餐；就寝取主要睡眠。 | 至少 2 个样本才显示数值，分钟数约到 5 分钟；不是 SRI 或健康分。 |
| 餐间隔长短波动 | 所有有效同日间隔的总体标准差。 | 是间隔长短的描述，同时包含一日内不同餐间隔与跨日差异；无健康阈值。 |
| 睡眠偏短提示 | 至少 3 个完整日，至少 3 日时段合计不足 420 分钟，且这些完整日平均低于 420 分钟。 | 7 小时来自成人共识；3 日是产品最小观察门槛，不是疾病定义。只给成人作息提示，不给风险百分比。 |
| 靠近睡前提示 | 至少 3 组有效配对，且至少 3 次间隔小于 120 分钟。 | 120 分钟是描述性范围，3 次是减少偶发提醒的产品门槛；不推断餐量、食物构成、脂肪或疾病。反酸建议保留条件。 |
| 时刻波动提示 | 至少 5 个完整日，首餐或就寝环形标准差大于 60 分钟。 | 5 日及 60 分钟均为产品提醒门槛，未经临床验证，只说“安排有变化”，不称疾病风险。 |
| 总体状态 | 成人适用范围内有提示则显示提醒；无提示时至少需 5 个睡眠日、5 个饮食日、3 个睡前配对，否则“记录不足”。 | 即便数据足够也只说“暂未触发习惯提醒”，不能说“健康”或“无风险”。其他人群保持趋势模式。 |

## 验收

`npm test` 包含 17 项计算验证、两次独立 Electron 进程的实际持久化交互验收，以及既有 14 项图标验证。交互验收直接使用生产 `main.js`、preload、页面及 JSON 保存逻辑，但以临时独立用户目录运行，结束后删除测试资料。v1.2.1 针对改动执行了计算和交互验证，既有图标资产未变化。

覆盖：跨午夜、夏令时、跨时区配对排除、漏记、午睡、输入错误、未结束睡眠、时刻环形统计、证据 ID、增加/编辑/删除、真实进程重启、保存失败回滚、30 天切换、980×640 窗口及原有各栏目。截图中的示例记录仅属于测试目录，不写入使用者的饮食或睡眠资料。
