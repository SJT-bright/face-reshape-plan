# 1.4.0：20 项优化的使用与迁移说明

本轮保留六个业务栏目，新增独立“设置”。构建产物与测试使用当前工作区源码，未替换用户日常应用，也未读写真实健康资料。逐项证据见 [验收清单](20项体验优化-验收清单.md)。

## 常用入口

| 要做的事 | 入口与行为 |
| --- | --- |
| 第一次使用 | 首页“选择使用模块”进入设置；勾选所需模块并保存，或直接跳过。新资料不再凭空创建晚间训练安排。 |
| 开始/继续训练 | 首页首屏选择视频、继续上次跟练或继续力量训练；两类训练保留各自状态。恢复的视频初始暂停，点播放才计时。 |
| 记一餐 | 首页“记一餐”→“记录”，两次点击保存当前时刻。可以改为半小时前或自选时间。 |
| 记睡眠 | 首页“记睡眠”；检查昨晚入睡/起床时间，可填实际睡眠分钟数。跨度 8 小时、实睡 430 分钟时，统计使用 430 分钟。 |
| 记皮肤 | 首页“记皮肤”，或护肤→皮肤记录；缺数据先显示缺失项，不显示默认正常。 |
| 做护理 | 护肤→今日护理，先显示当前时段下一步；可本时段全部完成并立即撤销。 |
| 逐组训练 | 力量训练→今日训练→逐组记录；各组独立填重量/次数，点“完成本组”才计入统计。下一组带入上一组数值，仍需确认完成。 |
| 调整资料/目标 | 设置→个人资料 / 目标与外观。缺年龄、性别或活动水平时不擅自补值。修改每日跟练目标从今天生效。 |
| 调整提醒 | 设置→提醒，含护理三时段、皮肤、睡眠、复盘、勿扰和总开关。“今日提醒”可现在做、10 分钟后、今天跳过。 |
| 比较照片 | 护肤→照片与趋势→角度、基准与对齐比较。选择同类同角度照片，同步或单独缩放/平移，勾选透明叠加。日期间隔可见。 |
| 照片与视频文件 | 护肤页皮肤照进「皮肤照片」，健身体型照进「健身照片」；本地视频复制到「跟练视频」。可把文件直接放进对应文件夹再点读取。设置里也能打开这三个文件夹。 |
| 批量导入 | 首页视频库/导入入口；每行一个 BV、av 或链接，支持分 P。逐项列出成功、重复、失败和取消，失败可单独重试。 |
| 文件搬家 | 首页→视频库→本地视频卡→重新定位文件；保留视频 ID、计划绑定与历史。 |
| 找回草稿 | 返回对应页面/弹窗自动恢复；设置→数据与备份→管理草稿可检查或放弃。草稿不计入统计。 |

保存失败时，应用保留填写并回退已提交数据模型，显示“重试保存”；只有主进程确认写盘后才提示成功。`Cmd/Ctrl+S` 提交当前可保存表单，`Cmd/Ctrl+1…6` 切六个业务栏目。`Esc`、点弹窗外侧或“关闭”保留草稿；“放弃本次草稿”明确清除。输入法组合输入期间不会触发提交。

## 完整备份与恢复

1. 设置→数据与备份→导出完整备份，选择 `.frbackup` 保存位置。完整包包括各模块记录、设置、照片、相对路径和 SHA-256 校验清单，默认不包含 API 密钥。
2. 本地视频默认只保留路径引用；需要带走视频时勾选“包含本地视频”。照片和视频文件总计最多 512 MB；缺失文件会在预览中列出。视频过大时使用引用模式并另外保管原文件。
3. 恢复时先选择并检查备份，界面显示格式版本、创建日期、条目数量、照片、视频及缺失项。确认后先保留恢复前快照，再替换正式数据。损坏清单、越界路径或不支持版本会被拒绝；中断恢复可回滚。
4. 自动 JSON 备份仅包含记录和设置，不包含照片/视频；设置页显示最近成功时间。力量页的导出仍只包含力量数据。

恢复前快照位于当前资料目录的 `restore-before-时间-序号/`。完整包不会带走草稿、本次未结束的视频会话或密钥。恢复后可继续使用原机器的安全密钥；在新机器需要重新配置自己的密钥。

## 旧资料会怎样变化

- `uxVersion=1` 只迁移一次。已有安排、启用偏好和记录保留，老用户不被强制重做引导。
- 没有真实目标历史的旧记录，以升级时的目标作“迁移参考值”；不会伪造过去设置。已迁移日期保留快照，今后修改不倒改过去的达标结果。
- 原力量身体资料复制为共享个人资料，并保留未知扩展字段；后续编辑同步给营养和力量模块。未填写的资料保持空值。
- 旧力量汇总仍为汇总，不虚构各组重量与次数。首次改为逐组记录会提示替换该动作汇总。未修改汇总值的普通保存不会抹去已有逐组事实。
- 旧照片角度保持“未标注”，原图不变。对齐参数单独保存，导出恢复保留角度与比较设置。
- 旧 AI 明文密钥必须经系统加密、回读成功后才清理。系统安全存储不可用时明确报错，不改用明文；迁移失败时保留旧原值以便用户处理。成功迁移后清理自动 JSON 备份中的旧密钥字段。
- 草稿按模块、日期和编辑对象隔离，超过 30 天或表单版本不兼容时不自动应用；原记录变化时提示先去管理草稿查看，避免覆盖新记录。

## AI 与评分说明

AI 默认手动触发；用户明确开启自动模式后，进入皮肤记录页会使用当天最新皮肤照片，每日去重。请求前后显示照片日期、服务商/模型和状态。页面切换后的旧响应不写入新表单；识别结果先预填，人工保存后才成为正式记录。本轮所有 AI 请求测试使用替身与合成数据，没有发送真实个人照片，也没有验证服务商当前账号额度或计费。

皮肤、睡眠、饮食习惯、肌群与专注均有可展开的来源说明。缺失不作零值；只有明确手动暂停参与新的专注参考，缓冲、后台与未知暂停独立记录。既有算法阈值未在本轮新增；说明和参数来源仍在项目的相应算法文档中。

## 本轮验证边界

在当前 Apple Silicon Mac 上完成领域回归、隔离 Electron 操作、双窗口尺寸、日夜外观、120% 缩放、实际本地媒体拖动/倍速/重启恢复，以及跨域播放器桥测试。另有单独的在线 B 站公开视频探针，结果仅代表测试时可用，不保证所有 BV、分 P、地区和登录状态都可播。

通知逻辑使用可检查替身与可控时钟；macOS 真实通知权限和长时间睡眠后的系统送达未强行操作。Windows、Intel Mac、签名公证、用户真实资料迁移和日常安装替换不在本轮实测范围。测试与构建通过不等于这些环境已经验收。
