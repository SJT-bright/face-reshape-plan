# 今日饮食参考与面部状态建议 —— 调研与设计

> 交付位置：①「饮食与睡眠」页新增《🍚 今日饮食参考》卡（宏量营养素目标 + 今天已记录餐次）；
> ②护肤页新增《🧭 面部状态与建议》卡（AI 识图新增面部三字段 → 作息/饮食提示）。
> 纯函数：`rhythm-engine.js` 的 `nutritionAdvice` / `summarizeMealsToday`；`skin-engine.js` 的 `saveFaceState` / `latestFaceState`。

## 1. 营养口径（每条标注出处）

| 项目 | 规则 | 出处 |
| --- | --- | --- |
| 基础代谢 | Mifflin-St Jeor（与力量板块同式；年龄缺省按 30 并注明） | Mifflin 1990 |
| 维持热量 | BMR × 活动系数（久坐 1.2 / 轻度 1.375 / 中度 1.55 / 高 1.725） | 同力量板块口径 |
| 蛋白质 | 规律力量训练 1.6 g/kg；周刺激组 >20 → 1.8 g/kg（均取 ISSN 运动人群带 1.4–2.0 内）；无训练记录 1.2 g/kg——高于中国 DRIs 2023 成人 RNI ≈0.98 g/kg（18–64 岁；65 岁以上 1.17 g/kg）、低于 ISSN 带下限 1.4 的保守取值 | ISSN（Jäger 2017）；中国 DRIs 2023 |
| 蛋白分配 | 分 3–4 餐，每餐参考 ISSN 单次剂量带 0.25–0.4 g/kg（0.25 g/kg ≈20–40g；全食餐与年长者取上端约 0.4）；实际进食次数折算高于 0.4 g/kg 时提示可加一餐 | 同上 |
| 脂肪 | 供能 25% 起步（AMDR 20–30% 中点）；碳水越出 50–65%E 时在 20–30%E 带内调脂肪让位，仍不可行（蛋白供能 >30%）则如实披露 | 卫健委 2017 标准（AMDR）/ ACSM |
| 碳水 | 蛋白与脂肪定后的余量供能 ÷4，受 50–65%E 约束（见上行调整规则），同时给出 g/kg 对照 3–5 | 卫健委 2017 标准 / ACSM |
| 饮水 | 30–35 ml/kg（通行经验值，非指南原文），夹在 1500–2500ml（上限为应用自定） | 中国居民膳食指南 2022（1500–1700ml） |
| 固定提示 | 盐 <5g/天；添加糖 <50g/天（最好 <25g，本应用按更严一档提示） | 中国居民膳食指南 2022 |

诚实性边界：**应用只记餐次时间（刻意不记食物构成）**，所以「今天吃了多少」只如实展示 N 餐、首次/末次与进食跨度，不虚构热量/宏量统计；数字是**推荐摄入目标**，不是实际摄入；免责注明非医疗建议（肾病、孕期等遵医嘱）。

## 2. 面部状态（AI 识图扩展）

GLM-4V 提示词在原 9 项皮肤参数外新增三字段（**主观视觉印象，非测量**）：

| 字段 | 含义 | 0 → 3 |
| --- | --- | --- |
| fullness | 面部圆润饱满感（苹果肌/颊部） | 清瘦 → 很圆润 |
| puffiness | 晨起水肿感（眼周/面部） | 无 → 明显 |
| definition | 下颌线与轮廓清晰度 | 模糊 → 很清晰 |

- 校验沿用既有严格口径（`normAiInt` 0–3，小数/越界/缺失一律拒绝；三项全无效则整体不入档、不影响 9 项填充计数）。
- 存储独立于皮肤评分（`db.skin.faceState[date]`），14 天内有效（AI 依赖照片，过期不解读）。
- 建议映射（护肤页《面部状态与建议》卡）：
  - 水肿感 ≥2 → 晚餐少盐少酒、按睡眠建议早睡（钠/酒精/睡眠不足与晨起浮肿相关，生活习惯参考）；
  - 圆润感 ≥2 → 面部脂肪随**全身体脂**变化，「局部瘦脸」训练/按摩无可靠证据——对照试验 Vispute 2011（6 周腹部训练）未发现局部训练减少腹部脂肪的效果，不支持「局部减脂/瘦脸」说法；路径是温和热量缺口 + 全身训练；
  - 圆润感 ≤1 → 提醒勿过度节食（保证蛋白与总热量，过快减脂显疲态）；
  - 轮廓清晰度 ≤1 → 体脂下降时下颌线通常更清晰（个体差异大，主观观察）。
- 卡片同时给当前时段的护肤基础项：早 = 温和清洁+保湿+防晒 SPF30+；晚 = 清洁+功效成分（视黄醇类夜间、低频起步）+保湿修护（皮肤科通行基础建议，AAD）。
- 诚实性：卡片标题与页脚均注明「主观视觉印象 · 非测量、非诊断」；不宣称能从照片测出「肉有多少克」。

## 3. 主要来源

- ISSN 蛋白质立场声明：[Jäger 2017, JISSN](https://www.tandfonline.com/doi/full/10.1186/s12970-017-0177-8) · [PMC5477153](https://pmc.ncbi.nlm.nih.gov/articles/PMC5477153/)
- 中国居民膳食指南 2022（盐 <5g、添加糖 <50g 最好 <25g、饮水 1500–1700ml）：人民卫生出版社官方版
- 蛋白 RNI（≈0.98 g/kg〔18–64 岁，男 65g/女 55g〕、65 岁以上 1.17 g/kg）：中国 DRIs 2023，中国营养学会；[新华社专家解读](http://www.xinhuanet.com/food/20231103/b0edcf0354804d2eb6bc4c1972964771/c.html)
- 供能比带（碳水 50–65%E、脂肪 20–30%E、蛋白 10–15%E）：卫健委标准《中国居民膳食营养素参考摄入量 第1部分》（2017 年发布）[PDF](https://www.nhc.gov.cn/wjw/yingyang/201710/fdade20feb8144ba921b412944ffb779/files/1739783563332_90405.pdf)。注：本应用按该 2017 标准口径执行；2023 版 DRIs 的供能比口径未在本次检索中逐条核验，不做等同声称
- 局部减脂：[Vispute 2011, JSCR（该试验条件下未发现腹部训练减少腹部脂肪的效果）](https://pubmed.ncbi.nlm.nih.gov/21804427/)
- ACSM/ADA/DC 联合立场（脂肪 20–35%E、碳水 3–5 g/kg 中等负荷）：Rodriguez 2009, Med Sci Sports Exerc
- 防晒与护肤基础：American Academy of Dermatology 通行建议（SPF 30+、夜间视黄醇低频起步）
