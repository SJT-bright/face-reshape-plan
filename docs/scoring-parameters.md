# 评分参数溯源总表

> 覆盖四套评分/建议体系：皮肤评分（含痘痘）、肌肉进步、睡眠质量、营养参考。
> 每个参数标注证据层级：**[A] 文献原值**（直接采用发表的数值/公式）、**[B] 文献带内取值**（文献给区间，应用取区间内一点）、**[C] 设计决策**（无文献给定，明示为设计选择）。
> 原则：[C] 不得在 UI 里伪装成文献结论；[A]/[B] 必须可回溯到下方来源。

## 1. 皮肤评分（scoreSkin，0–100）

| 参数 | 值 | 层级 | 说明 |
| --- | --- | --- | --- |
| 痘痘计分方法 | 病灶计数（总数+新增） | [A] | 痤疮临床试验以炎性/非炎性**病灶计数**为主要终点（FDA 痤疮试验指导），IGA 0–4 为全局分级口径——计数法是临床标准做法 |
| 痘→坏度曲线 | badness = min(4, 总数/5) + min(2, 新增)，再 /4 归一 | [C] | 封顶与线性折算无文献唯一解；20 颗封顶防个别极端值吞掉整卡 |
| 各维度权重 | 痘 30%、屏障 14%、泛红 13%、眼周 11%、毛孔 10%、斑 8%、肤感 8%、干 6% | [C] | 文献不提供合成权重；排序原则：炎症/屏障 > 纹理 > 干燥。UI「查看权重口径」已明示 |
| 主客观融合 | 客观 70% + 自评整体 30% | [C] | 无文献给定融合比；纯客观会忽略使用者感受，纯主观会被当天情绪支配 |
| 维度分级 | 0–3 四档自报 | [B] | 与 IGA 的有序分级思想一致（0=好 → 3=严重），但为自报而非医师评估 |
| 基线对比 | 前 28 天各维度**中位数** | [C] | 中位数抗离群；28 天约一个皮肤更新周期（角质层更新约 28 天，[B] 文献常见口径） |

## 2. 肌肉进步（buildMuscleProgress，0–100）

| 参数 | 值 | 层级 | 说明 |
| --- | --- | --- | --- |
| 每周组数推荐带 | 10–20 刺激组 | [A] | Schoenfeld 2017 剂量反应荟萃、Baz-Valle 2022 |
| 组数完成度曲线 | 10 组→90 分，10–20 组线性到 100，>20 组回落到 85 | [C] | 剂量反应为连续曲线的呈现方式是设计选择 |
| 次数刺激折算 | 5–30 次全额；1–4 次 ×0.6；>30 次 ×0.7；未记 ×0.85 | [B] | 5–30 次为肌肥大有效区（各负荷区间增肌相当，Schoenfeld 载荷综述）；1–4/30+ 的具体折算系数为设计取值 |
| 1RM 估算 | ≤8 次 Brzycki；9–10 次 Brzycki/Epley 平均（±5%） | [A] | LeSuer 1997 公式验证；仅对 ≤10 次接近力竭成立 |
| 趋势抗波动 | 每动作取前两高记录平均 | [C] | 抗单次偶然波动 |
| 合成权重 | 增肌 0.6/0.25/0.15；力量 0.7/0.2/0.1；综合 0.45/0.45/0.1 | [C] | 文献不提供唯一合成比 |
| 主/辅肌群计组 | 主 1、辅 0.5 | [C] | 常见训练实践口径 |
| 耐力分数语义（v2） | 绝对常模分：单组表现对照动作路径（L1 锚点相对负荷 → L2 动作常模表 → L3 家族负荷档 → L4 通用宽档）→ 0–100，录入当天即有分；肌群分 = 各动作分最高值（峰值），同分依次按路径 L1>L2>L3>L4 → 最佳组次数多者 → 动作名升序仲裁 | [C] | 峰值依据 1RM/举重「取最佳试举」惯例 [A]；辅助肌群权重不打折动作分；「五档标准带为骨、分段线性计分表为形」结构借军队计分制与 Strength Level 惯例 [A/B] |
| 耐力 L1 锚点相对负荷 | pct = 组负荷 ÷ 同动作同 28 天窗锚点（≤10 次负重组 top-2 e1RM [A]+[C]）；受理域 pct ∈ [0.40, 0.833] 且 ≤30 次；预测次数 r = 30×(1/pct − 1) [A·Epley]，倍数 m = 实际次数 ÷ r 经锚点表 [[0,0],[0.5,20],[1,50],[1.5,75],[2,92],[2.5,100]] 分段线性 → 分（m=1 人群平均=50） | [A]+[C] | 受理域两端排除轻负荷端反解失真与力量区间组 [C]；锚点组自身在受理域内时同样参与（§3.5）；经典公式在 60–70% 1RM 预测不准且因动作而异（Hoeger 1987、Shimano 2006、Nuzzo 2023 综述），同动作个体化锚定为其缓解；锚点表形状参照 AFT「前陡后平」结构 [A/B]，锚点值无文献唯一解 [C] |
| 耐力 L2 动作常模表 | 俯卧撑（Golding/YMCA 20-29）、卷腹（ACSM 20-29）[B·上线前须人工复核原文]；仰卧起坐（女：中国标准大一大二 [B·较可信]；男无可靠表 → 走 L4）；引体 [C·低置信占位，来源未定位]。档位带：很差 0–15/差 20–34/中下 35–44/中等 45–59/中上 60–74/良好 75–89/优秀 90–100，档内按「次数下限 → 带下限」线性插值，优秀档「+15 次 →100」封顶 | [B]+[C] | 分档带对齐 4 档 UI 的细分 [C]；表值逐条溯源见 docs/endurance-norms-research.md |
| 耐力 L3 家族档 / L4 宽档 | 自重家族按有效负荷 %BW 分档（俯卧撑 0.64、跪姿 0.49 [B·Ebben 2011]；引体 1.0 [C·算术]；双杠 0.70 [C·设计初值，文献缺口]）查对应次数曲线；其余动作走通用宽档 [[3,20],[8,35],[15,50],[25,68],[35,82],[50,93],[65,100]] | [B]+[C] | 用户体重不参与（负荷档是动作属性而非用户属性，§2.4）；L4 的 50 分 = 普通成人单组 15 次宽档中心，大重量低次数组得低分是正确语义 |
| 耐力性别/年龄缺省 | 取 bmiProfile.sex/age；未填性别 → 男/女锚点逐点中值合并宽松档，且峰值走 L2/L3 时置信度封顶 limited；任何年龄一律按 20-29 表处理 | [C] | 常模切点 [A/B]；「缺省 + 披露」沿 rhythm-engine 先例；身高体重不参与耐力评分 |
| 耐力趋势 chip | enduranceChangePercent = 峰值动作的比值跨窗趋势（优先：11–30 次负重组、复用 Epley 反解比值）或同路径绝对分差（回退），clamp ±50；首窗必 null | [C] | 比值公式偏差跨窗同向抵消；分数封顶 100 后进步会饱和，如实允许 null |
| 耐力动作内取最优 | 动作分 = 本窗最佳单组得分：逐组记录逐组计分；汇总文本可解析逐组序列按序列最佳；均值组计分并标 degraded（不进输出字段，留返回结构） | [C] | top-2 均值会拉低峰值、单组偶然性由窗口聚合与置信度吸收；均值不可能超过真实最佳组，低估如实标注 |
| 抗疲劳保持率/耐力带占比/容量（展示统计） | fatigueRetentionPercent（保持率均值）、enduranceZoneSharePercent（≥12 次且 ≤67% 1RM 占比 [A·ACSM]）、repVolumeChangePercent（Σ次数环比 ±50%）退出合成，v1 公式不变，仅作展示 | [C] | 峰值原则下组间衰减不改变峰值，修正项会造成「多组记录反被扣分」；容量累加与峰值原则构造性冲突 |
| 综合分耐力分支 | 耐力分非 null 时：0.35 力量/0.35 增肌/0.2 耐力/0.1 频率；仅力量 0.45/0.45/0.1；仅耐力 0.5 增肌/0.3 耐力/0.2 频率；双 null 0.85/0.15。enduranceScore null ⟺ 近窗无任何已知次数组（与 v1 判据一致） | [C] | 四分支公式与置信度基础规则不变，唯一下调为峰值走合并档 L2/L3 封顶 limited；迁移影响见 docs/muscle-endurance-design.md §13 |

## 3. 睡眠质量（sleepQuality，0–100）

| 参数 | 值 | 层级 | 说明 |
| --- | --- | --- | --- |
| 时长分带 | 6.5–9h 满分 45，越短扣分快、过长缓扣 | [B] | NSF 成人 7–9h 的带内插值 |
| 深睡参考 | 18% ±10 个百分点 | [B] | 正常睡眠结构 N3 约 13–23%（Carskadon & Dement；各来源 10–25%），18% 为带中取值 |
| REM 参考 | 20% ±12 个百分点 | [B] | 正常 REM 约 20–25%，20% 为带内取值 |
| 夜醒扣分 | 每次 −3，未知给 6/10 | [C] | 无文献唯一扣分值 |
| 晨起感受 | 1→6 … 5→20，未知给 14/20 | [C] | 设计分档 |
| 手工分融合 | 手工 60% + 计算 40% | [C] | 尊重自评主导，设计取值 |

## 4. 营养参考（nutritionAdvice——目标口径，非评分）

详见 docs/nutrition-advice-design.md。关键参数层级：蛋白 1.6/1.8 g/kg [A]（ISSN 1.4–2.0 带内）、1.2 g/kg [C]（保守取值，高于 DRIs 0.98、低于 ISSN 下限 1.4）；脂肪 25%E [B]（AMDR 20–30% 中点）；碳水余量受 50–65%E 约束 [A]；饮水 30–35 ml/kg [C]（经验值，指南给 1500–1700ml）。

## 5. 面部状态（AI 三字段）

圆润感/水肿感/轮廓清晰度 0–3：**主观视觉印象，非测量**（照片无法估计脂肪克数）；仅用于建议映射，不参与任何评分权重。

## 6. 饮食规律（rhythm analyze）

只做**描述性统计与提醒**（进餐间隔、首次进食波动、睡前进食），不合成综合分——时间口径的「饮食好坏」无公认合成公式，不制造伪评分。

## 7. 血糖友好习惯参考（glycemicScore，0–100；habit-based，非血糖测量）

| 因子 | 权重 | 口径 | 层级 |
| --- | --- | --- | --- |
| 甜食档位（无/少量/适量/偏多 → 100/85/60/30） | 0.45 | 目标「添加糖 <50g、最好 <25g」[A]（中国居民膳食指南 2022）；四档克数估区与系数映射 [C]；应用只记档位不记克数，属自报估算 | A（目标）+ C（映射） |
| 进食跨度 | 0.30 | ≤12h → 100；12–14h → 70；>14h → 40 [B-观察性]（限时进食与血糖反应的研究）；小时阈值映射 [C] | B + C |
| 末次进食时刻 | 0.25 | ≤20:30 → 100；20:30–21:30 → 75；>21:30 → 50 [B-观察性]（生物钟下调晚间糖耐量）；阈值映射 [C] | B + C |

- 缺任一因子按剩余权重归一（如未选甜食档：跨度 0.30/0.55、晚间 0.25/0.55）；全缺返回 null，不虚构分数。
- **与大脑的关系只做关联性表述**：血糖大幅波动与注意力下降/困倦感的证据多为观察性与机制性（葡萄糖波动→精力感受），本分**不测量血糖、不预测认知表现**；糖尿病等血糖疾病请遵医嘱。
- 命名为「习惯参考」正是为了与真实血糖指标区分。

## 8. 专注参考（focusScore，0–100）

| 参数 | 值 | 层级 | 说明 |
| --- | --- | --- | --- |
| 打断定义 | 仅明确手动暂停计 1；技术/后台/未知暂停独立记录，恢复不计 | [C] | 1.4.0 起仅使用来源为 media-observed 的新条目；历史无法区分原因时不生成新分数 |
| 扣分映射 | 每 10 分钟 1 次打断扣 20 分（密度线性），0 次满 100，下限 0 | [C] | 无「看视频打断与专注力」的定量文献映射——如实标注为设计取值；选择密度制（而非绝对次数）是为了长视频不被不公平惩罚 |
| 评估门槛 | 单条目 <5 分钟不评估 | [C] | 过短会话无专注意义 |
| 展示边界 | **后台静默记录**（训练条目的 interruptions 字段），跟练页与今日页**零显示**；仅在成就日历按日展示按时长加权平均分 | [C] | 应用侧设计约束（用户要求） |
