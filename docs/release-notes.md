人生重塑计划 1.8.6 与 Mac 版使用同一套源码，提供 Windows x64 安装包和免安装完整 ZIP。两个平台的源码均在同一公开仓库，采用 MIT 许可证。

- 护肤主操作改为「开始护肤」：打开摄像头立即录像，点「结束视频」完成本次护肤；流程步骤只作参考。
- 力量训练时机突出显示「开始锻炼」的钟点（加餐后 1 小时、正餐后 2 小时）。
- 本地视频（含已下载的抖音）用第一帧作封面。
- Windows 记录、照片、跟练视频、生活视频和护肤录像写在 `%APPDATA%\面部重塑计划\`，安装和卸载保留用户资料。

安装版下载 `*Setup.exe`；免安装版完整解压 `*Windows-x64.zip` 后双击「人生重塑计划.exe」。`SHA256SUMS.txt` 提供校验值，`windows-validation.json` 提供打包程序检查记录。

Windows 安装包未配置 Authenticode 签名。自动测试使用合成照片与视频，不代表真实摄像头、在线视频或付费 AI 服务验收。

详见 [Windows 使用说明](https://github.com/SJT-bright/face-reshape-plan/blob/v1.8.6/WINDOWS-%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E.md)。
