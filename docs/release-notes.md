人生重塑计划 1.8.8 提供 macOS / Windows 共用的 MIT 开源源码。

- 瘦脸跟练增加可拖动的动作对照镜像小窗，实时看自己跟练。
- 睡眠时长蓝线增加等距小时刻度与 7 小时目标，另绘制橙色时长评分虚线；每日时长、分数与相邻差值明确显示。评分为实际分钟 / 420 × 100，最高 100 分，原手填自评分保留。
- 晚间护肤录像保存麦克风声音，可右键“转文字并存入复盘”：本地 ASR 转写 → 本地大模型删除口水词 → 追加至个人积累库当天复盘。晨间录像不进入这条链路，原录像/原稿/清稿分别保留，失败从相应阶段重试，同一录像不会重复追加。
- 护肤和复盘到点自动弹出全屏置顶窗口并开始计时；当前录像或自动流程结束后处理排队项。
- 自定义喝水、运动等周期提醒：名称、间隔和完成按钮可改，稍等 5 分钟后再弹，确认完成才增加每日次数。

安装和卸载继续保留本机资料。Windows 安装版下载 `*Setup.exe`，免安装版完整解压 `*Windows-x64.zip` 后打开「人生重塑计划.exe」。Mac 使用 arm64 包，运行说明见仓库 `MAC-使用说明.md`。校验值与 Windows 原生打包程序检查结果随 Release 提供。

本地转写与清稿需已有 FunASR Python/模型、FFmpeg、Ollama qwen3:14b；每日复盘写入需个人积累库服务。安装包不附带这些模型和运行环境，缺少依赖会显示具体错误，不切换到云端语音识别。macOS 已用合成中文视频跑通真实本地 ASR、模型清稿、隔离复盘 API 与界面交互；真实摄像头/麦克风设备与 Windows 本地模型运行需在相应机器上确认。
