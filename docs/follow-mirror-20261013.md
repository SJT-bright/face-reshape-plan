# 跟练动作对照小窗

在「瘦脸护理 → 沉浸式跟练」的播放器上方点击「开启动作对照」。摄像头画面以镜像显示，拖动小窗标题栏可移动，也可聚焦标题栏后使用方向键移动。小窗会限制在窗口可见范围内，应用的「沉浸全屏」模式下仍然可用。

此功能只申请视频流，关闭麦克风，不创建照片或录像，也不调用护肤录制器。正常的跟练时长与训练记录继续由视频播放状态决定。摄像头预览被排除在播放器的播放、暂停和计时判断之外。

关闭小窗、结束本次跟练、切换栏目或退出应用时释放摄像头。若请求尚未返回就关闭，返回的过期视频流也会立即释放。权限拒绝或摄像头断开时提供设置或重试入口；镜头默认不自动打开。

已开启摄像头的自动跟练流程使用此预览小窗，训练后的拍照与护肤流程保持原有行为。其他视频板块暂不显示这个入口。
