# 3D 素材与提示词

使用内置 image_gen.imagegen 逐项生成，共 37 份素材：34 种功能图标、1 个品牌标识、2 种按钮材质。

透明 PNG 原图位于 `src/assets/3d/originals/`，256px 图标和 1024px 按钮材质由 `npm run assets:3d` 导出。图像仅做尺寸导出，保留原始透明通道。文字与点击行为仍由 DOM 承担。
