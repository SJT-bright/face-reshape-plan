# v1.2.1

睡眠改为早晨按手环数据在页面内一次录入，移除“准备睡了”“我醒了”“补记睡眠”入口和进行中横幅。起床日期采用所选日期，跨午夜自动推算；下一次可沿用上次的时间微调。

可选填手环实际睡眠时长，平均时长和偏短提醒优先使用该值。未填写时，继续按入睡到起床的时段估算。填写的分钟数须为正整数，且不能超过时段跨度。这是手动转录，不会连接或自动同步手环。

旧版未完成记录保留在折叠区域，可整理或删除，不再阻塞后续完整睡眠统计。新版必须一次填写完整的入睡和起床时间，记录保存同时提交表单中的完整性确认。

每日训练目标原有入口保持不变：训练计划 → 快捷导入下方的“每日目标与提醒” → 每日瘦脸目标（分钟） → 保存设置。此值对应右上角目标总分钟数。

验证：17 项计算测试、独立临时用户目录中两次 Electron 进程的保存和重启验收、980×640 布局。
