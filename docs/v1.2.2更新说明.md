# v1.2.2 — 达标月历

- 将原来月份错位的 16 周热力图替换为月历，按周一至周日排列，日期直接显示在格子里。
- 支持选择年月、上月、下月和回到今天；未来日期不可补记。
- 区分未记录、已训练、已达标，格子显示训练时长，达到每日目标才显示绿色勾选。
- 点击日期查看当天训练明细、距目标剩余时长，以及当月训练天数、达标天数、累计时长。
- 手动补记自动带入所选日期，保存后同步刷新该日期；补记日期和时长有有效范围检查。
- 保留原来的半透明背景、生成的 3D 图标和按钮，以及所有原有记录。
